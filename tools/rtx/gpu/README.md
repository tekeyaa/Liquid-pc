# Обучение Liquid RTX на своей видеокарте

Та же сеть, что в браузере, но учится на видеокарте NVIDIA через PyTorch, примерно в 50–100 раз быстрее,
чем на процессоре, и на твоих видео. Готовые веса встают в Liquid без переделок.

## Что нужно
- Видеокарта NVIDIA (RTX 2060 и выше) со свежим драйвером.
- **Python 3.12** с [python.org](https://www.python.org/downloads/). При установке отметь «Add python.exe to PATH».
- **ffmpeg**: в терминале `winget install Gyan.FFmpeg`, потом открой новое окно.
- Около 10 ГБ на диске (PyTorch ~5 ГБ и данные).
- Видео, на которых учиться. Лучше всего **4K с высоким битрейтом** (фильмы, ролики с YouTube в 4K, свои записи
  игр). 1080p тоже годится: его кусочки сначала уменьшаются вдвое, чтобы «оригинал» был чистым.
  Для аниме-сети нужна отдельная папка с аниме и мультиками. Лучше 10–30 разных видео, чем одно длинное.

## Шаги
1. **`1-setup.bat`** — ставит PyTorch с CUDA (один раз, ~5 ГБ). В конце должно быть написано
   «Видеокарта: NVIDIA GeForce RTX …».
2. **`2-data.bat`** — перетащи папку с видео в окно, нажми Enter, дай имя (`video` или `anime`).
   Нарезает 800 кусочков, это 10–30 минут. Получится `video.npz` (~1 ГБ).
3. **`3-train.bat`** — выбери сеть (`pro` для обычного видео, `anime` для аниме) и файл данных.
   100 000 шагов на RTX 4070 идут примерно 30–60 минут; сколько осталось, пишется в окне.
   Каждые 2000 шагов сеть проверяется на кусочках, которых она не видела:
   ```
   проверка 31.42 дБ (было 31.05)  ✓ сохранено
   ```
   Чем больше число, тем лучше. Сохраняется только вариант, который лучше начального.
   Остановить можно в любой момент через Ctrl+C, лучший результат уже сохранён.
4. Готовый файл — `liquid-rtx-pro.json` (или `liquid-rtx-anime.json`) в этой папке.
   **Посмотреть сразу самому:** положи его в `%APPDATA%\Liquid\rtx\` (вставь этот путь в адресную строку
   Проводника, папку `rtx` создай) и перезапусти Liquid. Браузер возьмёт твои веса вместо встроенных (нужна версия 1.20.1+).
   Не понравилось — удали файл оттуда. Понравилось — пришли его в чат Claude: он проверит сеть на своих кадрах
   и выпустит в обновлении для всех.

## Тонкости
- По умолчанию сеть **дообучается** из нынешней (файлы `liquid-rtx*.json` рядом): так она не забывает старое.
  С нуля: `.venv\Scripts\python train_gpu.py --net pro --data video.npz --scratch --steps 300000`.
- Несколько наборов сразу: `--data video.npz anime.npz games.npz`.
- **Детальнее «на глаз»** (экспериментально): `--percept 0.02`. Сеть будет дорисовывать текстуру (траву, волосы,
  ткань), но число «проверка» упадёт, поэтому сохраняется каждая проверка, а судить нужно глазами.
  В первый раз скачается VGG16 (~530 МБ).
- Продолжить прерванное: `--resume liquid-rtx-pro.json.pt`.
- «Видеокарта: НЕ ВИДНА» — обнови драйвер NVIDIA и запусти `1-setup.bat` ещё раз.
- Памяти почти не нужно: данные ~1 ГБ видеопамяти, сама сеть — мегабайты.
