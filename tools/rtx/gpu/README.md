# Обучение Liquid RTX на своей видеокарте

Liquid сам собирает данные с YouTube: пары «кадр в 1080p → тот же кадр в 4K/8K». Где есть 8K, образцом берётся
8K, уменьшенный до 4K: он почти без следов сжатия. Сеть учится на твоей видеокарте NVIDIA и превращать то, что
YouTube отдаёт в 1080p, в чистую картинку уровня 4K. Готовые веса браузер подхватывает сам.

## 1. Собрать данные (в браузере)
Настройки → Liquid RTX → **Режим обучения**.
- Смотри YouTube как обычно: ролики, у которых есть 4K или 8K, сами попадают в очередь.
- Можно добавить ролики списком ссылок в том же разделе.
- Кадры нарезаются в фоне скрытым окном без звука, **только когда ни одна вкладка не играет видео**, чтобы
  не тормозить. С ролика берётся 12 мест по 3 кусочка, это примерно 2–3 минуты на ролик.
- Там же видно, сколько собрано. Место под данные по умолчанию 1 ГБ: это ~1600 пар с ~45 роликов, для нашей
  сети этого хватает. Лучше много разных роликов (природа, города, игры, люди, текст), чем много одинаковых.
- Для аниме-сети лучше собрать отдельно: включи режим, смотри только аниме, потом учи с `anime`
  (см. «Тонкости», про папку).

## 2. Обучить (один раз поставить, потом запускать)
Нужно: видеокарта NVIDIA (RTX 2060 и выше) со свежим драйвером и **Python 3.12** с
[python.org](https://www.python.org/downloads/). При установке отметь «Add python.exe to PATH».

1. **`1-setup.bat`** ставит PyTorch (один раз, ~5 ГБ). В конце должно быть «Видеокарта: NVIDIA GeForce RTX …».
2. **`2-train.bat`** — выбери сеть (`pro` для обычного видео) и жди. 100 000 шагов на RTX 4070 идут
   примерно 30–60 минут. Каждые 2000 шагов сеть проверяется на кусочках, которых она не видела:
   ```
   проверка 31.42 дБ (было 31.05)  ✓ сохранено
   ```
   Чем больше число, тем лучше. Сохраняется только вариант лучше начального. Остановить можно через Ctrl+C.
3. **Перезапусти Liquid**: он возьмёт новые веса сам (они ложатся в `%APPDATA%\Liquid\rtx\`).
   Не понравилось — удали файл оттуда, вернутся встроенные. Понравилось — пришли файл в чат Claude:
   он проверит сеть и выпустит её для всех.

## Тонкости
- Сеть **дообучается** из нынешней, поэтому не забывает старое. Повторный запуск учит дальше уже твою версию.
- Данные лежат в `%APPDATA%\Liquid\rtx-learn\data`. Чтобы учить аниме-сеть отдельно, переложи собранное с аниме
  в другую папку и запусти: `.venv\Scripts\python train_gpu.py --net anime --data ПАПКА`.
- **Детальнее «на глаз»** (экспериментально): `.venv\Scripts\python train_gpu.py --net pro --percept 0.02`.
  Сеть будет дорисовывать текстуру (траву, волосы, ткань), но число «проверка» упадёт, поэтому сохраняется
  каждая проверка, а судить нужно глазами. В первый раз скачается VGG16 (~530 МБ).
- Продолжить прерванное: `--resume "%APPDATA%\Liquid\rtx\liquid-rtx-pro.json.pt"`.
- «Видеокарта: НЕ ВИДНА» — обнови драйвер NVIDIA и запусти `1-setup.bat` ещё раз.
- Запасной путь без браузера: `prep_youtube.py ссылки.txt yt.npz` (через yt-dlp, нужен ffmpeg:
  `winget install Gyan.FFmpeg`), потом `train_gpu.py --data yt.npz`.
