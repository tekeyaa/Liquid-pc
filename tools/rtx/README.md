# Как обучена нейросеть Liquid RTX

Сеть — маленькая свёрточная ×2 по яркости (как FSRCNNX / ArtCNN): свёртка 3×3 1→F, четыре скрытые 3×3 F→F с ReLU,
выход 3×3 F→4 — четыре подпикселя 2×2, которые добавляются к билинейному увеличению кадра.
Идея та же, что у NVIDIA RTX Video Super Resolution: учить не на «чистых» уменьшенных картинках, а на кадрах,
**уменьшенных вдвое и сжатых видеокодеком** (H.264 CRF 18–32, VP9 и AV1 CRF 24–44, часть — без сжатия, часть —
с лёгким размытием «камеры»). Тогда сеть одновременно убирает следы сжатия и восстанавливает детали.

- `prep.py` — пары «сжатый кадр → оригинал»: Urban100, BSD100, Sun-Hays80 (репозиторий jbhuang0604/SelfExSR),
  тестовые наборы cszn/KAIR, фото природы imageio `meadow_cube.jpg` (кроме одной грани — на ней проверка), картинки scikit-image.
- `train.py F H шагов выход.json` — обучение на numpy (без фреймворков): im2col-свёртки, обратное распространение
  вручную, Adam, косинусный спад шага, потери Шарбоннье. `gradcheck.py` сверяет градиенты с численными.
- Готовые веса — `main/rtx/liquid-rtx.json`; шейдеры из них собирает `webview-preload.js` (функция `netShaders`).

Проверка — на кадрах, которых сеть не видела (грань куба meadow, wikkie, bricks, кадр с текстом), через тот же код,
что работает в браузере (WebGL2 в Chromium).
