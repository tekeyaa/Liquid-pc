# Liquid — браузер

Минималистичный браузер в стиле liquid glass: вкладки, VPN по ключу и Claude прямо в боковой панели.

## Установка (Windows)
1. Открой [Releases](../../releases/latest) и скачай **Liquid-Setup.exe**.
2. Запусти его. Установщик сам поставит Node.js (если его нет), Electron и xray-core, соберёт браузер
   в `%LOCALAPPDATA%\Liquid` и сделает ярлыки.
3. Обновление — тот же Liquid-Setup.exe новой версии поверх старой. Настройки, вкладки, входы и ключи сохраняются.

Что изменилось в каждой версии — в [CHANGELOG.md](CHANGELOG.md).

Запасной путь без установщика: скачай код, запусти **install.bat**, а если сборка exe упала — **start.bat**.
Если GitHub не открывается и xray не скачался — положи `xray.exe` из
[Xray-core](https://github.com/XTLS/Xray-core/releases) (`Xray-windows-64.zip`) в папку `bin` и снова запусти установку.

## Как устроен репозиторий
- `main.js`, `main/` — главный процесс Electron: окна, VPN, блокировщик, перевод, журнал отладки, игровой режим.
- `preload.js` — мост интерфейса, `webview-preload.js` — инструменты на страницах сайтов (перевод, чтение, видео).
- `renderer/` — интерфейс: вкладки, адресная строка, настройки, стартовая страница, Claude.
- `vpn.js` — разбор ключей и запуск xray.
- `installer/` — исходники Liquid-Setup.exe на Go.
- `.github/workflows/release.yml` — при каждом изменении в `main` собирает установщик и выкладывает релиз
  с номером из `package.json` и описанием из `CHANGELOG.md`.

Новая версия: подними `version` в `package.json`, добавь раздел в `CHANGELOG.md` и отправь в `main`.

## VPN
Кнопка **VPN** → вставь ключ → «Подключить». Ключ хранится зашифрованным (Windows DPAPI).
Поддерживаются: `vless://` (reality, tls, ws, grpc, xhttp, httpupgrade), `vmess://`, `trojan://`,
`ss://` (в т.ч. Outline), `ssconf://`, `socks5://`, `http://`.
VPN действует только на этот браузер, остальная система не трогается.

## Claude
Кнопка **Claude** (Ctrl+J) открывает панель справа. Два режима (⚙️ → «Как подключаться»):
- **Мой аккаунт claude.ai** (по умолчанию, ключ не нужен) — в панели открывается обычный claude.ai, входишь своим аккаунтом
  один раз, подписка работает как на сайте. Кнопка «Страница» вставляет текст открытого сайта прямо в чат.
- **API-ключ** — встроенный чат, Claude сам видит страницу. Ключ создаётся на console.anthropic.com и оплачивается отдельно от подписки.

Правый клик по выделенному тексту → «Спросить Claude».
Защита от фишинга работает в обоих режимах: без ключа — базовая проверка (двойники сайтов, подозрительные домены),
с ключом — плюс умная проверка через Claude.

## Горячие клавиши
Ctrl+T новая вкладка · Ctrl+W закрыть · Ctrl+L адрес · Ctrl+Tab листать · Ctrl+F поиск по странице ·
Ctrl+J Claude · Ctrl +/−/0 масштаб · F5 обновить · Alt+←/→ назад/вперёд · F12 инструменты разработчика
