# Нейросеть Liquid RTX

`liquid-rtx.json` — веса свёрточной сети ×2 по яркости, которой Liquid увеличивает видео (Liquid RTX, ступень «нейросеть»).
Обучена самим проектом (скрипты и описание — `tools/rtx`): кадры уменьшены вдвое и сжаты H.264 / VP9 / AV1, сеть учится
восстанавливать оригинал — одновременно убирает следы сжатия и возвращает детали. Шейдеры WebGL2 из весов собирает
`webview-preload.js` (функция `netShaders`), веса страницам отдаёт main (`sr:net`).

`liquid-rtx-pro.json` — большая сеть (24 канала, 5 скрытых слоёв) для мощных видеокарт: точнее на тексте и мелких деталях.
Если кадры не успевают, браузер сам переходит на `liquid-rtx.json`.

`liquid-rtx-anime.json` — сеть для аниме и мультиков (обучена на рисованных кадрах): ровные заливки, чистые контуры.
Включается, когда браузер распознал рисованное видео, или вручную (Настройки → Liquid RTX → Содержимое).
